# 四级背词小窗

这是一个 Windows 桌面背词工具。你可以听单词发音、自测拼写和释义，再用错词本集中练习。**第一次用，下载 ZIP、解压、双击程序，就可以开始背。**

## 下载和打开

1. [下载 Windows 版 ZIP](https://github.com/zhanglele0927/cet4-desktop/archive/refs/heads/main.zip)，也可以在仓库首页点 **Code → Download ZIP**。
2. 右键 ZIP，选择「全部解压缩」。把解压后的整个文件夹放到你有写入权限的位置，例如「文档」。
3. 打开解压后的文件夹，双击 **CET4Desktop.exe**。程序会读取同目录的词表和脚本，请把这些文件和 EXE 放在一起。

## 第一次背词

1. 看小窗里的英文单词。想听发音，点单词旁边的 **朗读**，它会用电脑的系统语音播放。
2. 如果想自测，先点 **隐藏中文**。确认自己已经认识这个词，点 **认识**，小窗会记录结果并直接切到下一词。
3. 如果不认识，点 **不认识**。小窗会显示答案并把词加入错词本。照着输入英文单词和一条正确的中文释义，然后在中文框按 **Enter** 进入下一词。你也可以直接用这套输入流程练习，提交成功会把该词记为「不认识」。
4. 想回看刚才的词，点 **上一词**。顶部进度显示当天已完成的词数。

例如，看到 **acquire** 时，已经知道它是「获得」就可以点「认识」。如果需要练习，先在英文框输入 `acquire`，再在中文框输入 `获得` 并按 Enter。小窗会把它留在错词本里供你复习。

## 怎么复习

| 入口 | 什么时候用 |
| --- | --- |
| 今日新词 | 继续当天的背词计划。每天最多安排 100 个新词，实际数量取决于词库和剩余进度。 |
| 错词本 | 想马上重练刚才标为「不认识」的词。 |
| 到期复习 | 想练已经到了复习时间的词。刚记为「不认识」的词约 10 分钟后到期。 |
| 今日单词 | 想查看今天已背和还要背的词。 |

可以先背一组新词，再打开错词本回练，之后有空时处理「到期复习」。

## 进度保存和常见问题

- **关掉后怎么继续？** 从同一个解压目录重新打开程序。学习进度保存在该目录的 `learning-v2.json`。
- **换电脑怎么保留进度？** 先关闭小窗，再把整个解压目录复制到另一台 Windows 电脑上。
- **小窗缩到屏幕上边缘了？** 把鼠标移到屏幕顶边的细条上展开。可以在「更多」中关闭贴边自动隐藏。
- **朗读没有声音？** 先检查系统音量和输出设备，再检查 Windows 是否有可用的英语语音。
- **这个版本有多少词？** GitHub 公开版附带 **100 个核心词**，可以直接使用。完整高频榜和第三方音标、词频数据需按来源许可另行配置。

## 源码和许可

`AppHost.cs` 是启动器源码，`Widget-v2.ps1` 和 `Learning.ps1` 实现界面及学习调度。重建启动器时，先备份并移开现有的 EXE，再用 Windows PowerShell 5.1 运行 `Build-Host.ps1`。

可选数据文件放在程序同目录。主词库使用 `cet4-source.json`，排序文件 `frequency-order.json` 需覆盖所有主词条。音标和优先词表分别使用 `phonetics.json` 和 `priority-words.json`。
